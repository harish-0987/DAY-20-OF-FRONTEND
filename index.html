Section 01

What is CSS Grid Layout?

CSS Grid Layout is a two-dimensional layout system for the web. Unlike Flexbox (which is primarily one-dimensional: either rows OR columns), CSS Grid enables you to control both columns and rows simultaneously.

💡 The 2D Revolution: With CSS Grid, you can align elements into fixed, fractional, or auto-adapting tracks across both the horizontal (inline) and vertical (block) axes at the exact same time.

The 6 Pillars of Grid Anatomy

Visual Grid Anatomy: Columns, Rows, Lines & Cells display: grid; gap: 16px;
Cell (1, 1) Box 1
Cell (1, 2) Box 2
Cell (1, 3) Box 3
Cell (2, 1) Box 4
Cell (2, 2) Box 5
Cell (2, 3) Box 6
1. Grid Container The parent element with display: grid that establishes the grid formatting context.
2. Grid Items (Boxes) Direct children inside the container that populate grid cells.
3. Grid Lines The numbered dividing lines (1, 2, 3...) that define column and row boundaries.
4. Grid Tracks The space between any two adjacent grid lines (a complete row or column).
5. Grid Cell The fundamental single unit intersection between one row track and one column track.
6. Gutters (Gap) The empty space between tracks defined by the gap property.

Write the HTML Structure

Create a parent container <div class="grid-container"> with child box elements inside:

<!-- Basic HTML Grid Box Structure -->
<div class="grid-container">
    <div class="grid-box">Box 1</div>
    <div class="grid-box">Box 2</div>
    <div class="grid-box">Box 3</div>
</div>
2

Apply the Basic CSS Grid Rules

Turn the container into a grid with display: grid, declare column widths, and set spacing with gap:

/* Basic Level CSS Grid Box */
.grid-container {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr; /* 3 equal flexible columns */
    gap: 15px;                          /* 15px space between boxes */
}

/* Styling the individual boxes */
.grid-box {
    background-color: #6366f1;         /* Indigo background */
    color: #ffffff;                    /* White text */
    padding: 20px;                     /* Inner box padding */
    border-radius: 8px;                /* Rounded corners */
    text-align: center;                /* Centered text */
    font-weight: 600;
}

Breaking Down the Basic Code

display: grid; Required

Turns the container element into a grid parent. All immediate children immediately become flexible grid boxes.

grid-template-columns Columns

Specifies the number and width of each column. 1fr 1fr 1fr creates 3 equal columns that automatically stretch and shrink.

gap: 15px; Spacing

Sets the gutter space between rows and columns without needing ugly margin hacks on child elements.

repeat(3, 1fr) Shorthand

A convenient shorthand function that repeats identical columns: repeat(3, 1fr) is identical to 1fr 1fr 1fr.

🌟 What is the fr unit? fr stands for Fractional Unit. 1fr represents one part of the available space inside the grid container. If you have grid-template-columns: 1fr 2fr;, the second column gets twice as much space as the first!
Section 03

CSS Grid Container Properties (Parent)

These properties are applied directly to the parent element to define tracks, sizing, gaps, and cell alignment.

grid-template-columns Container

Defines column track widths using pixels, percentages, fractions (fr), repeat(), or minmax().

.container {
    /* 3 equal columns */
    grid-template-columns: repeat(3, 1fr);

    /* Fixed sidebar + fluid content */
    grid-template-columns: 240px 1fr;
}
grid-template-rows Container

Defines explicit row heights. If omitted, rows will automatically size to fit their child contents.

.container {
    /* Header (70px), content (auto), footer (60px) */
    grid-template-rows: 70px auto 60px;
}
gap / row-gap / col-gap Container

Controls gutter spacing between items. gap: 20px; applies 20px between rows and columns.

.container {
    gap: 20px;             /* row & col gap */
    row-gap: 30px;         /* only rows */
    column-gap: 15px;      /* only cols */
}
justify-items & align-items Alignment

Aligns all grid items inside their cells along the inline (horizontal) and block (vertical) axes.

.container {
    justify-items: center; /* start | end | center | stretch */
    align-items: center;   /* start | end | center | stretch */
    place-items: center;   /* shorthand for both! */
}
grid-template-areas Template Areas

Visual ASCII-art style layout definition by naming specific grid areas.

.container {
    grid-template-areas:
        "header  header"
        "sidebar content"
        "footer  footer";
}
minmax() & auto-fit Responsive

The ultimate responsive pattern: automatically generates columns that wrap without writing media queries.

.container {
    /* Auto responsive columns, min 200px wide */
    grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
}
Section 04

Grid Item Properties (Children Placement)

Grid items can be made to span multiple columns or rows, or be explicitly placed at precise grid line numbers.

grid-column: span X Spanning

Allows a box to stretch across multiple horizontal column tracks.

/* Box spans across 2 columns */
.featured-box {
    grid-column: span 2;
}

/* Or from Line 1 to Line 3 */
.banner {
    grid-column: 1 / 3;
}
grid-row: span Y Spanning

Allows a box to stretch vertically across multiple row tracks.

/* Box spans across 2 vertical rows */
.tall-box {
    grid-row: span 2;
}

/* Or from Line 1 to Line 4 */
.sidebar {
    grid-row: 1 / 4;
}
grid-area Named Area

Assigns an item to a named area defined in grid-template-areas.

header { grid-area: header; }
aside  { grid-area: sidebar; }
main   { grid-area: content; }
footer { grid-area: footer; }
justify-self & align-self Item Align

Overrides the parent's alignment for an individual grid item.

.special-box {
    justify-self: end;    /* align right inside cell */
    align-self: center;   /* align vertical center */
}

Section 07

CSS Grid vs Flexbox: When to Use Which?

Both layout systems are complementary. The golden rule is: Flexbox is for 1D content-driven flows; CSS Grid is for 2D layout-driven structures.

Feature CSS Flexbox CSS Grid
Dimensionality 1-Dimensional (Row OR Column) 2-Dimensional (Rows AND Columns simultaneously)
Approach Content-first (items dictate size) Layout-first (container defines track framework)
Best Used For Navbars, button sets, media items, chips Page layouts, image galleries, dashboards, card systems
Item Placement Sequential ordering via order Arbitrary 2D positioning via line numbers or areas
Overlapping Items Difficult (requires negative margin / absolute) Native (items can share cells and overlap with z-index)
Section 08

CSS Grid Quick Cheat Sheet

display: grid;

Initializes a block-level grid container.

grid-template-columns: repeat(3, 1fr);

Creates 3 equal-width columns.

gap: 20px;

Sets 20px space between grid rows & columns.

grid-column: span 2;

Makes an item stretch across 2 column tracks.

grid-row: span 2;

Makes an item stretch vertically across 2 row tracks.

place-items: center;

Centers all items horizontally and vertically in cells.
